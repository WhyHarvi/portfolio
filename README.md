# Harwinder Sidhu Portfolio

A modern personal portfolio for Harwinder Sidhu, built with React, Tailwind CSS, GSAP, and Vite. The site highlights selected projects, experience, achievements, contact links, and a polished dark visual style with scroll-based animations.

## Features

- Animated hero section with custom loader
- Selected work section with stacked project cards and project detail modal
- About and experience section with scroll-based text reveal
- Contact/footer section with interactive headline and social links
- Custom 404 page with astronaut space illustration
- SEO metadata, Open Graph tags, structured data, and robots file
- Optimized bundle splitting with lazy-loaded sections

## Tech Stack

- React
- Vite
- Tailwind CSS
- GSAP + ScrollTrigger
- Framer Motion

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Run lint checks:

```bash
npm run lint
```

Preview the production build:

```bash
npm run preview
```
